# Bookstore API – Spring Boot RESTful Application

A fully functional backend application built using **Spring Boot**, offering secure **JWT-based authentication**, full **CRUD operations for books**, **filtering**, **pagination**, **sorting**, and complete **Dockerization**. Designed to follow clean architecture and REST principles.

---

## Key Features

- JWT Authentication (Signup + Login)
- Book Management (Create, Read, Update, Delete)
- Filtering by author, category, rating, title
- Pagination & Sorting
- Centralized Exception Handling
- Dockerized for easy deployment

Also, the backend is deployed in render
Link -> https://bookstore-app-e36i.onrender.com

Docker hub --> uttaran29/bookstore-app-deployment

To run this project use the following command->

-mvn clean install

-mvn spring-boot:run
